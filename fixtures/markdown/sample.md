# Read without leaving your work

This is a real Markdown file shipped with Marklight. You can read it with the
same renderer used for your own local documents. No account or network is
needed.

> [!TIP]
> Use the outline on the left to jump between sections. On a narrow window,
> open it with the outline button in the toolbar.

## Find a thought

Open search with **Cmd/Ctrl+F** and look for **waypoint**. The match counter
shows where you are, and Enter moves to the next result.

## Follow a local link

[Open the companion page](sample-guide.md) to see a second file in this bundle.
Use Back in the toolbar or **Option/Alt+Left** to return here.

## Copy the original code

The Copy button keeps the source text, including the final newline:

```sh
printf '# My notes\n\nA little breathing room.\n' > notes.md
```

## Try your own document

Choose **Open file** or drop a `.md` file into the window. Your documents stay
on your computer. When you save a changed file in another app, Marklight
reloads it while keeping your reading place where possible.
